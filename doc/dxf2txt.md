# DXF 到 SpatialLM 文本转换工具 (`dxf2txt.py`)

该脚本将三维模型从 DXF 格式转换为适用于 SpatialLM 项目的简化文本表示。它提取房间、门和窗的几何信息，并将其输出为 `Wall`、`Door` 和 `Window` 对象。

## 核心逻辑

转换过程遵循以下主要步骤：

1.  **文件解析与实体分组**:
    *   脚本首先使用 `ezdxf` 库读取输入的 DXF 文件。
    *   它会遍历模型空间（modelspace），查询并提取所有 `LWPOLYLINE` 和 `POLYLINE` 类型的几何实体，因为这些实体通常用于定义建筑元素的轮廓。
    *   通过调用 `parse_layer_name` 函数分析每个实体所在的图层名称（例如 `room_living_room_0`），脚本将实体分类为 "room", "door", 或 "window"，并根据图层名（如 `room_living_room_0`）将属于同一个建筑元素（例如同一个房间）的所有几何实体分组存放。

2.  **点提取与几何清理**:
    *   对于每个几何实体，脚本会提取其所有的顶点坐标。
    *   随后，脚本会调用 `remove_redundant_points` 函数对坐标点列表进行清理（此步骤可通过 `--no-point-cleanup` 参数禁用）。这个清理过程至关重要，它能确保几何形状的简洁性和准确性，具体包括：
        1.  **移除重复点 (`remove_duplicate_points`)**: 此函数会移除多边形轮廓中因闭合而产生的首尾重复点，以及其他距离过近的冗余点。
        2.  **移除共线点 (`remove_collinear_points`)**: 在移除了重复点之后，此函数会进一步简化多边形，移除那些位于两个顶点所构成的直线段上的中间点。这个过程会反复迭代，直到无法再简化为止。

3.  **从水平轮廓推断垂直面 (`infer_vertical_faces`)**:
    *   这是整个脚本的核心。脚本假设一个三维实体（如一堵墙）是由两个或多个处于不同高度（Z值）的水平多边形轮廓（例如墙的顶部轮廓和底部轮廓）以及连接它们的垂直面构成的。
    *   该函数首先筛选出每个实体组中的所有**水平多边形**（即所有顶点的Z坐标标准差非常小）。
    *   然后，它根据Z坐标的平均值对这些水平多边形进行分组，并找出最高和最低的Z值，从而确定该实体（墙/门/窗）的**高度**。
    *   最后，它遍历**底部轮廓**的每一条边。对于每一条边，它都生成一个对应的**垂直面**，并计算出该面的宽度、高度、三维空间中心点以及法向量。

4.  **墙体生成**:
    *   脚本首先遍历所有被分类为 "room" 的实体组。
    *   对每个 "room" 实体组调用 `infer_vertical_faces` 函数，得到构成该房间的所有垂直面。
    *   每一个符合最小宽度要求（`--min-wall-width`）的垂直面都被转换成一个 `Wall` 对象，并被分配一个全局唯一的ID。这些 `Wall` 对象被存储起来，作为后续门窗挂靠的基础。

5.  **门窗生成与墙体匹配**:
    *   完成所有墙体的提取后，脚本开始遍历被分类为 "door" 和 "window" 的实体组。
    *   与墙体生成类似，它对每个门/窗实体组也调用 `infer_vertical_faces` 来提取垂直面。
    *   对于每一个从门/窗实体中提取出的垂直面，脚本会调用 `find_matching_wall` 函数，在第4步生成的所有 `Wall` 对象中为它寻找一个最佳的“宿主”墙体。
    *   匹配的核心逻辑 `is_coplanar_and_center_in_wall` 函数包含两个关键检查：
        1.  **共面性**: 门/窗面必须与墙体在同一个平面上（通过检查两者法向量的点积是否接近1来判断）。
        2.  **位置关系**: 门/窗面的中心点投影到墙体基线后，必须落在基线的两个端点之间，且该中心点到墙体基线的垂直距离必须在容差范围（`--tolerance`）内。
    *   一旦找到距离最近且满足条件的墙体，脚本就会创建一个 `Door` 或 `Window` 对象，并记录下其所挂靠的墙体ID (`wall_id`)。

6.  **序列化与文件输出**:
    *   最后，脚本将内存中所有的 `Wall`, `Door`, `Window` 对象进行整理。
    *   它调用每个对象自带的 `to_language_string` 方法，将对象信息格式化为符合 SpatialLM 规范的文本字符串。
    *   所有字符串按 `Wall`、`Door`、`Window` 的顺序写入到指定的输出 `.txt` 文件中，完成转换。

## 数据结构

-   **`Wall`**: 由其基线的两个端点（`ax`, `ay`, `az`, `bx`, `by`, `bz`）、`height`（高度）和 `thickness`（厚度，当前固定为0）定义。
-   **`Door`**: 与一个 `wall_id` 相关联，并由其中心点（`cx`, `cy`, `cz`）、`width`（宽度）和 `height`（高度）定义。
-   **`Window`**: 与 `Door` 类似，也与一个 `wall_id` 相关联，并由其中心点、宽度和高度定义。

## 使用方法

该脚本可以通过命令行运行。

### 处理单个文件：

```bash
python tools/dxf2txt.py --input path/to/your_file.dxf --output path/to/your_output.txt
```

### 处理目录中的所有DXF文件：

```bash
python tools/dxf2txt.py --input-dir path/to/dxf_folder/ --output path/to/output_folder/
```

### 命令行参数

-   `--input-dir`: 指定包含DXF文件的输入目录。
-   `-o`, `--output`: 指定输出文件或目录。
-   `--tolerance`: 用于匹配门/窗与墙体的几何公差（默认值：`1e-3`）。
-   `--min-wall-width`: 一个几何面被视为墙体的最小宽度（默认值：`0.05` 米）。
-   `--point-tolerance`: 用于移除重复点和共线点的公差（默认值：`1e-6`）。
-   `--no-point-cleanup`: 一个标志，用于禁用整个点清理过程。
